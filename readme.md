# DesoutterSimulator

Desoutter 拧紧枪 OpenProtocol 模拟器(WPF),用于联调上位机客户端。

## 功能

- **多枪模拟**:每把枪独立 TCP 端口监听,端口号可在启动前编辑(启动后锁定)
- **状态展示**:每张枪卡片显示「未启动/已启动」「未连接/已连接」「使能」「程序号」「订阅」状态
- **日志页**:实时记录协议收发(含 MID 中文名),最多 1000 条;支持鼠标框选复制;光标在最后一行时自动跟随滚动,点击其他位置停止跟随并显示「回到底部」按钮
- **发送拧紧结果页**:选择结果 OK/NG、扭矩、角度、程序号后,向当前选中枪发送拧紧结果(MID 0061)
- **配置持久化**:添加/删除枪、保存/加载配置(`guns_config.json`)
- 基于 CommunityToolkit.Mvvm 实现 MVVM

## 支持的 MID

| 分类 | MID |
|---|---|
| 通信 | 0001 通信启动 / 0003 通信停止 / 9999 心跳 |
| 参数集 | 0010 ID上传 / 0012 数据上传 / 0014 订阅选中 / 0017 退订 / 0018 设定程序号 |
| 拧紧结果 | 0060 订阅 / 0063 退订 / 0064 旧结果上传 |
| 工具 | 0040 工具数据上传 / 0042 下使能 / 0043 上使能 |
| Job | 0030 ID上传 / 0034 订阅信息 / 0037 退订 / 0038 选择Job |
| VIN | 0051 订阅 / 0054 退订 |
| 报警 | 0070 订阅 / 0073 退订 / 0078 确认报警 |
| 其他 | 0080 读时间 / 0270 控制器重启 |

## 使用

1. 启动程序,在左侧枪卡片编辑端口号,点击「启动」
2. 客户端连接后,卡片显示「已连接」;发送 MID 0043 上使能后「使能」变为 True
3. 点击左侧枪 → 右侧「日志」页查看协议记录
4. 切换到「发送拧紧结果」页,选择 OK/NG 等参数,点击「发送拧紧结果」
